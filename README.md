# SCC Platform (prototype)

Safety Command Center local prototype: FastAPI backend + React/Vite UI.

Read `backend/README.md` and `frontend/README.md` for PowerShell setup.

Design and requirements remain in `docs/`. Sign in as **Admin** (`admin` / `admin`) or **Operator** (`operator` / `operator`). Operational records persist in SQLite at `backend/data/scc_platform.db`. SSO is not connected.
